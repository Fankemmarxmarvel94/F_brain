# Manga Rating App

Application web pour l'évaluation et la notation de mangas, développée avec Django, React et PostgreSQL.

##  Technologies

- **Backend**: Django 4.2+ (API classique)
- **Frontend**: React 18 + Vite + Tailwind CSS
- **Base de données**: PostgreSQL 15
- **Reverse Proxy**: Nginx
- **Conteneurisation**: Docker & Docker Compose
- **CI/CD**: GitHub Actions

##  Fonctionnalités

-  Catalogue de mangas avec informations détaillées
-  Système de notation (1-5 étoiles)
-  Commentaires et avis
-  Recherche et filtres avancés
-  Gestion des utilisateurs
-  Interface responsive
-  Authentification sécurisée
-  Statistiques et moyennes
